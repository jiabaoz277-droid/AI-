Agent：智能生视频 Agent

官方名称；契约来自公开 B2B API，不等同于消费者网页内部实现。

提交侧证据充分

1. 核心目标

根据文字提示和可选参考图/参考视频生成视频内容。

2. 触发条件

调用提交任务接口；必填服务标识和 prompt，参数通过校验与安全审核。

3. 六类输入

  • 当前输入：prompt（≤2000 字）、图片/视频 URL。
  • 长期信息：API 权限/配额可能被读取；账号偏好未知。
  • 项目上下文：比例、时长、语言、口音、水印。
  • 上游输出：可选参考素材；由谁生成未知。
  • 平台能力：官方备案的文本、图像、视频模型与安全规则。
  • 运行时：task_id、code、status、message、request_id。

4. 可观察判断

参数/素材限制、安全前后审、权限、并发与内部状态。创意规划与质量判断不可见。

5. 调用工具

  • 提交视频任务（官方 API 动作可见）。
  • 查询视频任务（官方 API 动作可见）。
  • 输入/输出安全审核（由错误码证实存在）。
  • 素材解码与限制校验（由错误码证实存在）。

6. 输出

  • 用户回复：API message。
  • 页面组件：不适用于公开 API；消费者 UI 未知。
  • 资产：视频内容是接口目标；实际结果结构未完整验证。
  • 状态：提交成功返回 task_id；查询状态存在。
  • 下游：预览、编辑、导出或发布均未知。

7. 完成条件

不能以“提交成功”当成视频完成；必须由查询任务返回完成状态且实际视频资产可读取。【建议设计】还需验证时长、比例、语言、口音、水印和内容一致性。

8. 异常与重试

参数/素材错误先修正；并发/QPS可退避；安全拦截不可盲目重试；内部错误可幂等重试。官方是否提供幂等键未知。
